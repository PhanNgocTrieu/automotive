# Glossary – Thuật ngữ Automotive / Embedded

| Thuật ngữ | Giải thích |
|---|---|
| **A2L** | File mô tả biến đo/tham số calibration (ASAM MCD-2 MC) |
| **ADAS** | Advanced Driver Assistance Systems |
| **AEC-Q100/Q200** | Chuẩn chất lượng linh kiện IC / thụ động cho ô tô |
| **ARXML** | File XML mô tả hệ thống AUTOSAR |
| **ASIL** | Automotive Safety Integrity Level (QM, A–D) |
| **ASPICE** | Automotive SPICE – mô hình đánh giá quy trình |
| **AUTOSAR** | AUTomotive Open System ARchitecture |
| **BCM** | Body Control Module |
| **BMS** | Battery Management System |
| **BSW** | Basic Software (AUTOSAR: Services, ECU Abstraction, MCAL) |
| **BswM / EcuM** | Mode manager / ECU state manager |
| **Bus-off** | Trạng thái node CAN tự ngắt khỏi bus khi TEC ≥ 256 |
| **CAN / CAN FD / CAN XL** | Controller Area Network và các thế hệ |
| **CDD** | Complex Device Driver; hoặc file CANdela diag description |
| **Com / PduR / CanIf / CanTp** | Module AUTOSAR communication stack |
| **CRC** | Cyclic Redundancy Check |
| **DBC** | File mô tả message/signal CAN (Vector) |
| **Dcm / Dem** | Diagnostic Communication Manager / Diagnostic Event Manager |
| **Det** | Default Error Tracer |
| **DID** | Data Identifier (UDS 0x22/0x2E) |
| **DoIP** | Diagnostics over IP (ISO 13400) |
| **DTC** | Diagnostic Trouble Code |
| **E2E** | End-to-End protection (CRC + counter) |
| **ECC** | Error Correcting Code |
| **ECU** | Electronic Control Unit |
| **EMC / EMI / ESD** | Tương thích điện từ / Nhiễu điện từ / Phóng tĩnh điện |
| **Fee / Ea** | Flash/EEPROM Emulation, EEPROM Abstraction |
| **FFI** | Freedom From Interference |
| **FiM** | Function Inhibition Manager |
| **FMEA / FTA** | Failure Mode and Effects Analysis / Fault Tree Analysis |
| **FTTI** | Fault Tolerant Time Interval |
| **HARA** | Hazard Analysis and Risk Assessment |
| **HIL / SIL / MIL / PIL** | Hardware/Software/Model/Processor-in-the-Loop |
| **HSM / HSE / SHE** | Hardware Security Module / engine trong MCU |
| **HPC** | High Performance Computer (central compute) |
| **IoHwAb** | I/O Hardware Abstraction (AUTOSAR) |
| **ISO 11898** | Chuẩn CAN |
| **ISO 14229** | UDS |
| **ISO 15765-2** | ISO-TP (CAN transport protocol) |
| **ISO 26262** | Functional safety ô tô |
| **ISO/SAE 21434** | Cybersecurity ô tô |
| **ISR** | Interrupt Service Routine |
| **KL15 / KL30 / KL31** | Ignition / Battery / Ground |
| **LDF** | LIN Description File |
| **LIN** | Local Interconnect Network |
| **Limp-home** | Chế độ chạy giới hạn khi có lỗi |
| **Load dump** | Xung quá áp khi ngắt ắc quy lúc máy phát đang sạc |
| **MCAL** | Microcontroller Abstraction Layer |
| **MC/DC** | Modified Condition/Decision Coverage |
| **MISRA C** | Bộ quy tắc lập trình C an toàn |
| **MPU** | Memory Protection Unit |
| **NM** | Network Management |
| **NRC** | Negative Response Code (UDS) |
| **NvM** | Non-volatile Memory Manager |
| **OBD-II** | On-Board Diagnostics |
| **OEM / Tier 1 / Tier 2** | Hãng xe / NCC hệ thống / NCC linh kiện, phần mềm |
| **OSEK** | Chuẩn RTOS ô tô, nền của AUTOSAR OS |
| **OTA** | Over-The-Air update |
| **PDU** | Protocol Data Unit |
| **PWM** | Pulse Width Modulation |
| **QM** | Quality Managed (không yêu cầu ASIL) |
| **RTE** | Runtime Environment (AUTOSAR) |
| **Runnable** | Hàm trong SWC được RTE lập lịch |
| **SBC** | System Basis Chip |
| **SDV** | Software-Defined Vehicle |
| **SecOC** | Secure Onboard Communication |
| **SENT / PSI5** | Giao thức cảm biến |
| **SOME/IP** | Scalable service-Oriented MiddlewarE over IP |
| **SOP** | Start Of Production |
| **SOTIF** | Safety Of The Intended Functionality (ISO 21448) |
| **SWC** | Software Component (AUTOSAR) |
| **TARA** | Threat Analysis and Risk Assessment |
| **TEC / REC** | Transmit / Receive Error Counter (CAN) |
| **UDS** | Unified Diagnostic Services |
| **VIN** | Vehicle Identification Number |
| **WCET** | Worst-Case Execution Time |
| **WdgM** | Watchdog Manager |
| **XCP** | Universal Measurement and Calibration Protocol |
