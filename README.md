# Automotive Embedded Learning

Tài liệu tự học để trở thành **Automotive Embedded / Firmware Engineer**, từ điện tử cơ bản đến các hướng chuyên sâu.

👉 **Bắt đầu từ [ROADMAP.md](ROADMAP.md)**

## Cấu trúc repo

```
.
├── ROADMAP.md                        Lộ trình tổng thể: nền tảng → chuyên sâu → thực tế → chuyên gia
│
├── automotive-firmware-knowledge/    GIAI ĐOẠN 1 – Nền tảng (~6 tháng)
│   ├── 00-electronics-fundamentals/    Điện tử cơ bản
│   ├── 01-automotive-fundamentals/     CAN, UDS, AUTOSAR, ISO 26262, ISO 21434, ASPICE, MISRA
│   ├── 02-firmware/                    MCU, startup/linker, RTOS, bootloader, NvM, debug
│   ├── 03-drivers/                     GPIO, Timer/PWM/ADC, UART/SPI/I2C, CAN, WDG
│   ├── 04-application/                 SWC, state machine, control, diagnostics, MBD
│   ├── 05-labs-projects/               Lab theo cấp độ + code mẫu + capstone
│   └── 06-references/                  Thuật ngữ, tài nguyên
│
└── specializations/                  GIAI ĐOẠN 2 – Chuyên sâu (chọn 1 hướng chính + 1 hướng phụ)
    ├── 01-autosar-bsw-mcal/
    ├── 02-diagnostics-bootloader-ota/
    ├── 03-functional-safety/
    ├── 04-cybersecurity/
    ├── 05-vehicle-networks-ethernet/
    ├── 06-motor-control-ev/
    ├── 07-adaptive-autosar-hpc/
    └── 08-test-validation-hil/
```

| Phần | Trạng thái |
|---|---|
| Giai đoạn 1 – Nền tảng | ✅ Đầy đủ tài liệu, lab và code mẫu |
| Giai đoạn 2 – Chuyên sâu | 🚧 Đã có đề cương từng hướng, các bài chi tiết sẽ viết dần |
